# پروژه اول بوت‌کمپ هوش مصنوعی کوئرا

## تحلیل و مدل‌سازی داده‌های آگهی‌های املاک دیوار

این پروژه در چارچوب پروژه اول بوت‌کمپ هوش مصنوعی کوئرا
در تابستان ۱۴۰۵ انجام شده است.

## اعضای گروه

- هلیا قلیچ خانی
- نرگس خسروی
- احسان رسولیان
- روح الله مفید
- مهدی هارونی

## معرفی پروژه

در این پروژه مجموعه‌داده‌ای شامل بیش از یک میلیون آگهی
املاک دیوار مورد بررسی و تحلیل قرار گرفته است.

هدف پروژه تحلیل آماری داده‌ها، بررسی فرضیه‌های مرتبط با
بازار املاک، خوشه‌بندی املاک و پیش‌بینی قیمت ملک است.

## بخش‌های پروژه

### بخش اول — معرفی و بررسی داده
- بررسی ویژگی‌ها
- بررسی داده‌های گمشده
- بررسی نوع متغیرها
- پیش‌پردازش داده

### بخش دوم — تحلیل آماری
- تحلیل توزیع دسته‌بندی‌ها
- بررسی سال ساخت
- بررسی روند آگهی‌های فروش و اجاره
- تحلیل قیمت فروش
- تحلیل جغرافیایی
- تحلیل قیمت اجاره
- محاسبه قیمت حقیقی
- ماتریس هم‌بستگی
- تحلیل امکانات ملک

### آزمون فرض
- مقایسه مساحت کلان‌شهرها و شهرهای کوچک
- مقایسه خانه‌های قدیمی و جدید
- بررسی اثر سند تجاری بر قیمت
- بررسی اثر امکانات لوکس و غیرلوکس بر قیمت

### بخش سوم — یادگیری ماشین

#### مسئله اول: سیستم توصیه‌گر
- انتخاب ویژگی
- K-Means با k=10
- انتخاب k مناسب
- DBSCAN

#### مسئله دوم: پیش‌بینی قیمت
- آماده‌سازی داده
- مهندسی ویژگی
- آموزش مدل
- Validation
- انتخاب مدل نهایی
- ارزیابی روی Test با R²، MAE و MSE
